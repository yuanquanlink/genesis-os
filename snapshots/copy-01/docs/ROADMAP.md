# Roadmap

## v1.0 Beta Planning (planned, no implementation in this phase)

The next milestone is a thirty-day, local-first product-validation cycle for the existing Personal AI Operating System Prototype. It prioritizes consented anonymous usage measurement, Daily Loop usefulness, Mission and Evidence quality, Memory precision, Mentor adoption, Provider resilience, and user-controlled recovery over new modules.

- **P0 must complete before wider beta**: consent/data controls, privacy-minimal analytics definitions, a beta operating guide, export/restore drill, and fallback observability.
- **P1 important optimization**: resolve measured Daily Loop friction, collect explicit Mentor-action feedback, surface stale candidates and broken provenance, add local health visibility, and make only evidence-backed mobile improvements.
- **P2 deferred**: cloud sync, multi-device support, public auth/multi-user collaboration, vector retrieval, broad integrations, and production code execution.
- **Future exploration**: a security-reviewed production architecture with authenticated accounts, managed persistence, authorization, encrypted backups, monitoring, rate limits, and private storage.

See `../GENESIS_OS_V1.0_BETA_VISION.md` for metrics, the 30-day protocol, beta exit criteria, and the public-product gap analysis. Do not begin Phase 6 automatically.
